# Security policy

DepScope does not yet have a configured private security contact or public release. Do not include secrets, private source code, or personal data in reports.

If you find a security issue in DepScope, avoid posting actionable exploit details publicly. The maintainer must configure a private reporting channel before public launch. Until then, contact the project owner through the private channel where this repository was provided and request an acknowledged disclosure path.

DepScope itself is not comprehensive malware detection or a guarantee that a dependency is safe. Its sources, heuristics, and coverage limits are documented in [the risk rules](docs/risk-rules.md). The unauthenticated HTTP API is intended for local use or a separately secured network boundary, not direct public exposure.
